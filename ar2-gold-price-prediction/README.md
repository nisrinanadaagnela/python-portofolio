# Gold Price Prediction using AR(2) Model

A time series analysis project applying an AR(2) (second-order autoregressive) model to predict the price of gold (per troy ounce) against the Indonesian Rupiah, based on historical price data.

## What it does

This project analyzes historical gold price data and builds an AR(2) model to forecast future prices. The workflow includes:

- Exploratory Data Analysis (EDA) of the gold price dataset
- Stationarity checks and data transformation (with AIC-based model tracing/selection)
- Building and fitting the AR(2) model
- Evaluating and visualizing the model's forecasting performance

## Tech stack

- Python
- pandas & NumPy (data processing)
- Matplotlib (visualization)
- Statistical/time series modeling libraries

## How to run

Open the notebook in Google Colab or Jupyter Notebook and run all cells in order.

## Note

This project was originally developed as a course assignment for Time Series Analysis, applying classical time series modeling (autoregressive models) to real-world financial data.
