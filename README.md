# Python Portfolio

A collection of Python projects from my undergraduate coursework and thesis research. My background is in Mathematics, so most of these projects apply Python to mathematical modeling, optimization, and data analysis.

## Recommended starting points

If you're short on time, these best represent my range of skills:

- **[thesis-product-selection](./thesis-product-selection)** — my undergraduate thesis, and the most comprehensive project here: a full pipeline combining web scraping, NLP-based sentiment analysis, and optimization.
- **[library-management-system](./library-management-system)** — a non-mathematical project showcasing core programming logic: OOP (classes & inheritance), functions, conditionals, and building an interactive interface.

## All projects

| Project | Description |
|---|---|
| [thesis-product-selection](./thesis-product-selection) | My undergraduate thesis: a full pipeline combining web scraping, NLP-based aspect extraction and sentiment analysis (Stanza, IndoBERT), feature weighting (BWM), and Binary Integer Programming (solved via the Balas algorithm) to optimize product selection based on real customer reviews. |
| [library-management-system](./library-management-system) | Digital library system with user roles (Admin/User), book borrowing & returns, and an interactive Gradio interface. Demonstrates OOP and general programming logic. |
| [seir-measles-control](./seir-measles-control) | Optimal control model for measles outbreak using the SEIR differential equation system, simulating the effects of vaccination, prophylactic treatment, immunoglobulin intervention, intensive treatment, and quarantine. |
| [neural-network-forecasting](./neural-network-forecasting) | An LSTM neural network model for forecasting time series data 20 periods ahead. |
| [dbscan-spatial-analysis](./dbscan-spatial-analysis) | Spatial analysis of weather station data in Canada using DBSCAN clustering, applied to identify potential areas for agroclimatology and tourism. |
| [ar2-gold-price-prediction](./ar2-gold-price-prediction) | An AR(2) time series model to predict gold prices (per troy ounce) against the Indonesian Rupiah. |
| [kkt-bond-optimization](./kkt-bond-optimization) | Optimization of bond sales strategy using the Karush-Kuhn-Tucker (KKT) method. |
| [kkt-gui-optimizer](./kkt-gui-optimizer) | An interactive GUI tool (Tkinter) that solves general constrained optimization problems using the KKT method, with user-defined variables and constraints. |
| [pert-cpm](./pert-cpm) | A project scheduling tool using PERT/CPM to visualize task timelines and identify the critical path — originally used to plan our own group project's workflow. |
| [interval-halving-wind-prediction](./interval-halving-wind-prediction) | Wind speed prediction using multiple regression models, with hyperparameters optimized via the interval halving (bisection) method to minimize RMSE. |

Python, NumPy, pandas, Matplotlib, scikit-learn, Gradio
