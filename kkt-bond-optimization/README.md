# Bond Sales Strategy Optimization using KKT Method

An optimization project applying the Karush-Kuhn-Tucker (KKT) conditions to determine the optimal bond investment/sales strategy, given a set of budget and tax constraints.

## What it does

Given an initial investment amount, tax-free limits, and tax rates, this project determines the optimal allocation of funds across multiple bond options (with different values/returns) to maximize investment outcomes, subject to constraints. It uses convex optimization to solve the allocation problem.

## Tech stack

- Python
- cvxpy (convex optimization solver)

## How to run

Open the notebook in Google Colab or Jupyter Notebook and run all cells in order.

## Note

This project was originally developed as a course assignment for Non-Linear Programming, applying the KKT method to a real-world financial decision-making scenario.
